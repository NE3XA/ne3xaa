If you are new

A simple path for beginners

  1. HTML — structure of a page (headings, paragraphs, links)
  2. CSS — colours, spacing, layout so it looks intentional
  3. JavaScript — make buttons and forms respond
  4. Git — save and share your work
  5. Python or JS deeper — pick one for scripts or more advanced web work

What you need

A browser (Chrome, Firefox or Edge). A free code editor is optional (VS Code is popular). No paid software required to start.

How long?

Most people can build a simple styled page in a few evenings. Consistency beats long marathon sessions.
